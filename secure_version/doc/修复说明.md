# 修复版安全改造说明

本目录（`secure_version`）已完成以下核心修复：

1. 认证与鉴权
- 登录成功返回 `Bearer Token`（HMAC 签名、含过期时间）。
- 业务接口不再信任 URL 中的 `user_id`，统一从 `Authorization` 头识别身份。
- 前端请求统一携带 `Authorization: Bearer <token>`。

2. SQL 注入修复
- 登录由字符串拼接 SQL 改为 ORM 条件查询。

3. 密码安全
- 用户密码改为 `PBKDF2-SHA256` 哈希存储。
- 兼容旧明文：首次成功登录后自动升级为哈希。

4. 越权（IDOR）修复
- `GET /api/profile/{profile_id}` 增加归属校验：考生仅可查看自己的档案。

5. 导入执行风险修复
- 成绩导入接口禁止公式字符串，移除 `eval` 执行链路。

6. XSS 风险降低
- 公告创建/编辑时对标题和内容做 HTML 转义后入库。

7. 暴力破解防护
- 登录失败计数、时间窗限制、短时锁定（429）。

8. CORS 收敛
- 由 `*` 收敛为本地开发前端白名单域名。

## 运行提示
- 旧的 `admission_user`（无 token）需先清理浏览器本地存储再登录。
- 如需更换 token 密钥，设置环境变量：`ADMISSION_TOKEN_SECRET`。
